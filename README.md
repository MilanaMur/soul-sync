## ✨ About

**SoulSync** — это веб-приложение для пар.

Идея проекта — создать небольшой цифровой уголок, где можно:
- делиться эмоциями
- сохранять воспоминания
- отслеживать настроение друг друга

Проект находится на ранней стадии разработки и пока представляет собой **frontend-прототип без backend-части**.

---

## 🚀 Features

Текущие реализованные элементы интерфейса:

### 💓 Love Ping
Небольшие "пинги" для партнёра — способ отправить сигнал внимания.

### ⚙ Setup
Экран настройки приложения.

### ⏱ Timer
Таймер, который может использоваться для совместных активностей.

### 🎨 Animated UI
Интерфейс использует **Framer Motion** для плавных анимаций.

## 📦 Installation

Клонирование репозитория:
```bash
git clone https://github.com/MilanaMur/soul-sync.git
```

Перейдите в директорию проекта: 
```bash
cd soul-sync
```

Установите зависимости: 
```bash
npm install
```

Запуск Dev-сервера
```bash
npm run dev
```
После запуска сервер будет доступен по адресу `http://localhost:5173`.


## 🧑‍💻 Development
### Requirements
- Node.js 18+
- npm

### Build  
Production сборка:

Preview production версии:
